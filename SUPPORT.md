# Support

Need help with QueryBridge? Here are the best ways to get assistance:

## Documentation
- Check the [README.md](README.md) for quick start and configuration guides.
- Explore the `examples/` directory (if available) for implementation patterns.

## GitHub Issues
- For bugs and feature requests, please open an [Issue](https://github.com/MythicalMAxX/QueryBridge/issues).
- Please provide as much detail as possible, including your environment and database type.

## Community & Discussions
- Join the [GitHub Discussions](https://github.com/MythicalMAxX/QueryBridge/discussions) to ask questions or share your ideas.

## Feature Requests
We are always looking for ways to improve QueryBridge. If you have a specific database you want supported or a tool you'd like to see added, please let us know via an issue.
